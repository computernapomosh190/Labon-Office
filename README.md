# Labon-Office
Створено ІТ інфраструктура офісу в pnetlab.З яких складаеться з серверів,роутерів сегментів мережі,VPN,IP телефоніі,відеоспостереження та робочих станції.

## ⚙️ Детальний опис сервісів та інфраструктури

Кожен сегмент мережі виконує чітко визначені бізнес-функції та містить розгорнуті сервіси:

### 🌐 Серверна зона (VLAN 10 — Server Room):
*   **WEB-Server:** Розгорнуто корпоративний сайт на базі **WordPress** для зовнішніх користувачів та внутрішня CRM-система **EspoCRM** для автоматизації бізнес-процесів.
*   **FTP-Server:** Організовано централізоване сховище файлів на базі **OpenWrt** з розмежуванням прав доступу.
*   **AD Controller:** Контролер домену **Active Directory** для централізованого керування користувачами, комп'ютерами та політиками безпеки в домені.
*   **Radius Server:** Забезпечує централізовану автентифікацію, авторизацію та облік (AAA) для мережевих пристроїв та користувачів.
*   **IP Telephony:** Внутрішній зв'язок та інтеграція з лініями зв'язку реалізовані на базі **AskoziaPBX**.
*   **CCTV-Server:** Сервер відеоспостереження із налаштованою та функціонуючою емуляцією потоків відеокамер для моніторингу безпеки.

### 🖨️ Зона друку (Print Server):
*   **Print Server:** Реалізований на базі окремого інстансу **OpenWrt**, де за допомогою технології віртуалізації USB (**vhci / virtual usb**) прокинуто та налаштовано спільний доступ до офісного принтера для мережевих користувачів.

### 🔐 Мережева безпека та доступ:
*   **Open-Wrt (Edge Router):** Виступає прикордонним маршрутизатором, забезпечує NAT, захист від зовнішніх загроз та піднімає **WireGuard VPN** тунель для безпечного віддаленого підключення співробітників (маршрутизація у внутрішню підмережу `10.0.0.0/24`).
*   **Mikrotik-CRS:** Виконує роль Core-комутатора/маршрутизатора, здійснює між-VLAN комутацію (Inter-VLAN routing) та ізоляцію трафіку згідно з політиками безпеки компанії.
