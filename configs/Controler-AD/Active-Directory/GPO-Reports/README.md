## 🌲 Централізоване управління (Active Directory & GPO)

Для централізованого керування користувачами та забезпечення безпеки робочих станцій розгорнуто доменну службу Active Directory. Усі налаштування виконано через графічний інтерфейс (GUI) Windows Server та повністю задокументовано.

### 🔐 Реалізовані груповые політики (GPO):
*   **Корпоративна політика паролів (Corp_Password_Policy):** Налаштовано вимоги до складності, мінімальну довжину пароля (від 10 символів) та автоматичне блокування облікового запису після 5 невдалих спроб введення.
*   **Обмеження периферії (USB_Restrict_Policy):** Заблоковано використання сторонніх USB-накопичувачів (флешок) для всіх відділів компанії, окрім сертифікованих пристроїв IT-департаменту.
*   **Обження доступ до панелі керування та командного рядка** Заблоковано звичайним користувачам відкриття налаштування панель керування
та вимкнення,перезавантаження серверу.

📋 *Повні інтерактивні HTML-звіти з конфігураціями кожної політики доступні для перегляду в папці `/configs/active-directory/gpo-reports/`.* [1]
