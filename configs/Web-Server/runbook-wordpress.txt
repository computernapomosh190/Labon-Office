
📘 RUNBOOK: Розгортання WordPress на стеку Nginx + MariaDB

Мета: Налаштувати та запустити систему керування контентом WordPress на сервері labon-srv (192.168.10.2),
використовуючи веб-сервер Nginx, СУБД MariaDB та інтерпретатор PHP 8.5,
з урахуванням низької швидкості локальної мережі (1 Мбіт/с) та ізоляції портів.

ПІДГОТОВКА:

Встановлення PHP 8.5 и модули для WordPress

sudo apt update
sudo apt install php8.5-fpm php8.5-cli php8.5-mysql php8.5-curl php8.5-gd php8.5-mbstring php8.5-xml php8.5-xmlrpc php8.5-soap php8.5-intl php8.5-zip -y

sudo systemctl enable php8.5-fpm
sudo systemctl start php8.5-fpm

📅 Етап 1. Створення бази даних у СУБД MariaDB
# Вхід до консолі MariaDB (використовуйте пароль root-користувача СУБД)
sudo mysql -u root -p
-- 1. Створення виділеної БД для сайту
CREATE DATABASE wordpress CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 2. Створення безпечного локального користувача
CREATE USER 'wp_user'@'localhost' IDENTIFIED BY 'wp_password123';

-- 3. Надання прав користувачу на створену базу
GRANT ALL PRIVILEGES ON wordpress.* TO 'wp_user'@'localhost';

-- 4. Оновлення таблиці прав та вихід
FLUSH PRIVILEGES;
EXIT;

📂 Етап 2. Завантаження та розгортання файлів двигуна
# Перехід у тимчасовий каталог
cd /tmp

# Завантаження останньої стабільної версії WordPress
wget https://wordpress.org

# Розпакування архіву (.tar.gz)
tar -xvf latest.tar.gz

# Створення цільової папки сайту та переміщення файлів
sudo mkdir -p /var/www/html/wordpress
sudo mv wordpress/* /var/www/html/wordpress/

# Видалення тимчасових залишків для економії місця на диску
rm -rf wordpress latest.tar.gz

🌐 Етап 3. Конфігурація віртуального хосту в Nginx

sudo nano /etc/nginx/sites-available/default

Знайдіть блок server { listen 80; ... } (або замініть його вміст) і приведіть його до такого вигляду:
3. Збережіть та закрийте файл (Ctrl+O -> Enter -> Ctrl+X).

🔑 Етап 4. Налаштування прав доступу під Nginx (www-data)

Щоб WordPress міг створювати конфігураційний файл wp-config.php, автоматично оновлювати плагіни та завантажувати картинки на сервер, 
веб-серверу Nginx потрібно дати права власника.

# Рекурсивно змінюємо власника папки на www-data (користувач Nginx)
sudo chown -R www-data:www-data /var/www/html/wordpress

# Виставляємо безпечні права (папки - 755, файли - 644)
sudo chmod -R 755 /var/www/html/wordpress

# Перевіряємо конфігурацію Nginx на наявність синтаксичних помилок
sudo nginx -t

sudo systemctl restart nginx


🎛 Етап 5. Конфігурація Port Forwarding на Mikrotik (DST-NAT)

Тепер зв'яжемо зовнішній запит користувача з вашим новим сайтом. Прокинемо унікальний зовнішній порт 8080 на внутрішній порт 80,
де Nginx тепер чекає на WordPress.

/ip firewall nat add chain=dstnat action=dst-nat to-addresses=192.168.10.2 to-ports=80 protocol=tcp dst-address=192.168.152.129 
dst-port=8080 comment="Website WordPress"


🚀 Етап 6. Графічна інсталяція в браузері

1. На робочій машині відкрийте браузер і перейдіть за адресою: http://192.168.152.129:8080
2. Оберіть Українську мову зі списку та натисніть «Вперед!».
3. Заповніть параметри підключення до MariaDB:
	• Назва бази даних: wordpress
	• Ім'я користувача: wp_user
	• Пароль: wp_password123
	• Сервер бази даних: localhost (оскільки СУБД працює на тому ж сервері, де й Nginx)
	• Префікс таблиць: wp_ (можна залишити стандартним)
4. Натисніть «Запустити інсталяцію».
5. Введіть назву сайту (наприклад, «Офіційний сайт labon IT»), створіть логін і пароль адміністратора для входу в адмінку (/wp-admin) та завершіть процес.
Сайт успішно розгорнутий на вашому LEMP-стеку!
