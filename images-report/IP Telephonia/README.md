### 📞 IP-Телефония (VoIP — MikoPBX)
Корпоративная телефонная сеть и маршрутизация вызовов внутри компании развернуты на базе современной IP-АТС **MikoPBX** (настроена через GUI, развернута в изолированном **VLAN 10 — Server Room**).

**Реализованный функционал:**
*   **Создание абонентов (Extensions):** Настроены внутренние трехзначные учетные записи SIP для сотрудников всех ключевых департаментов (Administration, IT, Accounting, Business).
*   **Безопасность сигнализации:** Для подключения софтфонов на рабочих станциях пользователей используется авторизация по парам `Логин / Сложный пароль`. Вся АТС защищена встроенным Firewall и модулем Intrusion Protection (защита от перебора паролей).
*   **Маршрутизация вызовов (Dialplan applications):** Разработаны правила прохождения звонков, обеспечивающие связь между отделами и регламентирующие доступ к внешним линиям.
*   **Хранилище (Storage):** Оптимизировано дисковое пространство MikoPBX для хранения системных логов и мониторинга доступности сервиса.
